# dkotlidas.com

Personal site of Dimitris Kotlidas: white label performance marketing for agencies.
Strategy and copy rules are in `BRIEF.md`, the build plan in `PLAN.md`, repo rules in `CLAUDE.md`.

## Stack

Vite, React 18, TypeScript, Tailwind, shadcn/ui, React Router. Every page is prerendered to static HTML with `vite-react-ssg`, so search engines and LinkedIn previews see the real content. Hosted on Vercel (`vercel.json`).

## Commands

```sh
npm install            # or npm ci
npm run dev            # local dev server on http://localhost:8080
npm run build          # prerendered site in dist/, plus sitemap.xml and 404.html
npm run preview        # serve dist/ locally
npm run lint
npm run typecheck
npm test
npm run check:confirm  # lists [CONFIRM] placeholders; must be empty before launch
```

## Editing content (no component changes needed)

| Privacy and cookie policy | `src/content/legal.ts` |
| Lead magnet popup (off until a provider exists) | `src/content/lead-magnet.ts` |

### Setting the next webinar

In `src/content/webinars.json`, copy the `nextExample` object into `next` and change `startsAt` (with time zone offset) and `lumaUrl`. The site shows the date in each visitor's time zone and hides it after the webinar ends. Set `next` back to `null` when there is no date.

### Adding a case study

Add an entry to `caseStudies` in `src/content/case-studies.ts`. The page `/case-studies/<slug>` and the sitemap entry are generated at build time.

## Tracking

GTM (`GTM-NTSC726P`) is the only script in `index.html`; do not edit those snippets. GA4, Meta Pixel and CookieYes run inside GTM. The site pushes typed events to the `dataLayer` through `src/lib/track.ts`. Event list and GTM setup: `docs/tracking-plan.md`.
